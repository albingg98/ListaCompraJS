# Lista de Compra JS
![javascript](https://github.com/user-attachments/assets/53fb9d89-7b79-4e62-8fcf-229b62555ef2)

Lista de Compra JS es una aplicación web sencilla desarrollada en JavaScript que permite a los usuarios crear y gestionar una lista de compras. La aplicación ofrece una interfaz fácil de usar para añadir, editar y eliminar elementos de la lista, ayudando a organizar las compras de manera eficiente.
Se puede acceder desde el siguiente enlace: https://silly-ardinghelli-affa9f.netlify.app/
## Características

- **Añadir Artículos**: Agrega productos a la lista de compras con un solo clic.
- **Editar Artículos**: Modifica la cantidad o descripción de los artículos existentes en la lista.
- **Eliminar Artículos**: Quita productos de la lista de compras de manera sencilla.
- **Interfaz Amigable**: Diseño minimalista y fácil de usar para una experiencia de usuario agradable.

## Tecnologías Utilizadas

- **Lenguaje**: JavaScript
- **Frontend**: HTML5, CSS3

## Instalación

1. Clona el repositorio en tu máquina local:
    ```bash
    git clone https://github.com/albingg98/ListaCompraJS.git
    ```
2. Navega al directorio del proyecto:
    ```bash
    cd ListaCompraJS
    ```
3. Abre el archivo `index.html` en tu navegador favorito para ejecutar la aplicación.
